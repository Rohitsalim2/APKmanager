# APK File Manager

File manager sederhana, cepat, dan **bebas iklan** untuk Android.

## Fitur
- 📁 Browse semua file & folder (internal + SD card)
- 🔍 Cari file instan
- ✏️ Rename, hapus, buat folder baru
- 📋 Copy, move, multi-select
- 🌙 Dark & light mode otomatis (ikuti sistem)
- 📱 Preview image, text, PDF, video, audio
- 🔐 Izin storage modern (Android 11+ support)
- 💾 100% Offline, gak perlu akun, gak ada tracking

## Download
**Versi terbaru:** [app-release.apk](https://github.com/Rohitsalim2/APKmanager/releases/latest/download/app-release.apk)

Atau buka halaman download: https://rohitsalim2.github.io/APKmanager/

## Build dari source
```bash
flutter pub get
flutter build apk --release --split-per-abi
```

## Tech Stack
- Flutter 3.27+
- path_provider, permission_handler, file_picker, mime
- Material 3 UI
